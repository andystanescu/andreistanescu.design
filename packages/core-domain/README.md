# Core domain utilities

This private package contains framework-independent theme, case-study and email-content utilities. It has no database, Next.js, add-on, portfolio content or asset dependencies. The app currently uses compatibility entry points in `src/lib`; it does not yet consume a packaged artifact. Build with `npm run build` from this directory. `npm pack` builds first and includes only the compiled files and this README.

This is an extracted part of Core, not the complete Core application or a buyer-ready product. Its exports are provisional until the wider platform and add-on compatibility contracts are established.
